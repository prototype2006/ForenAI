# 🕵️ ForenAI

> AI-powered Digital Evidence Analyzer for Digital Forensics

## Overview

ForenAI assists investigators in analyzing digital evidence using Artificial Intelligence.

The application supports document upload, OCR, NLP-based analysis, evidence classification, named entity recognition, suspicious keyword detection, timeline generation, and automated investigation report generation.

---

## Features

- 📂 **Evidence Upload:** Upload digital evidence files for analysis.
- 📄 **OCR & Text Extraction:** Extract text from supported documents and scanned evidence using Tesseract OCR.
- 🤖 **AI Summarization:** Generate concise summaries of extracted evidence using Hugging Face Transformers.
- 🔎 **Forensic Analysis:** Identify evidence-related identifiers, timestamps, and potentially relevant findings.
- ⚠️ **Suspicious Keyword Detection:** Planned or in progress, depending on the current implementation.
- 🗓️ **Timeline Generation:** Planned or in progress, depending on the current implementation.
- 📊 **Investigation Report Generation:** Planned or in progress, depending on the current implementation.

## Tech Stack

- **Language:** Python
- **Interface:** Streamlit
- **AI/NLP:** Hugging Face Transformers
- **OCR:** Tesseract OCR, pytesseract
- **Document Processing:** PyPDF2, python-docx, pdf2image
- **Image Processing:** Pillow
- **Version Control:** Git and GitHub
- **Database:** SQLite, only if implemented and used by the application
